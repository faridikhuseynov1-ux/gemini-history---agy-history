# agy-history 📚

> **Скилл для Antigravity CLI** — просматривай историю разговоров и **по-настоящему продолжай** любую прошлую сессию.

Когда ты пишешь `/history-browser` в AGY, этот скилл позволяет:
1. Видеть все прошлые разговоры (отсортированы по последней активности)
2. Выбрать любой и **продолжить его** — AGY читает **полный транскрипт**, понимает всё и продолжает как ни в чём не бывало

---

## ✨ Возможности

- 📋 **Список всех прошлых разговоров** с датой, числом сообщений и превью первого сообщения
- 🔍 **Поиск** по ключевому слову в истории разговоров
- 🔄 **Глубокое возобновление** — читает `transcript_full.jsonl` (полная, не обрезанная версия), восстанавливает весь контекст
- 📝 Отслеживает **изменённые файлы**, **запущенные команды**, **ошибки** из сессии
- 🔢 Размытое совпадение ID — достаточно первых 8 символов
- ⚡ CLI-команда `agy-history` доступна глобально в терминале

## 🚀 Установка

```bash
# Клонируй в директорию глобальных скиллов AGY
git clone https://github.com/faridikhuseynov1-ux/gemini-history---agy-history \
    ~/.gemini/skills/history-browser

# Зарегистрируй глобально (если ещё не сделано)
cat > ~/.gemini/config/skills.json << 'EOF'
{
  "entries": [
    { "path": "~/.gemini/skills" }
  ]
}
EOF

# Установи CLI-команду глобально
chmod +x ~/.gemini/skills/history-browser/scripts/agy-history
sudo ln -sf ~/.gemini/skills/history-browser/scripts/agy-history /usr/local/bin/agy-history
```

## 💻 Использование

### В чате AGY

Просто напиши:
```
/history-browser
```
AGY покажет список разговоров и спросит какой продолжить.

Или напрямую:
```
продолжи разговор 3ee8ab89
resume conversation 3ee8ab89
```

### В терминале

```bash
# Показать последние 30 разговоров
agy-history

# Поиск по ключевому слову
agy-history --search "docker"

# Показать последние 50
agy-history --limit 50

# Глубокое возобновление — полный контекст (хватит первых 8 символов ID)
agy-history resume 3ee8ab89

# Полный транскрипт без обрезки
agy-history resume 3ee8ab89 --raw

# Записать контекст в файл
agy-history resume 3ee8ab89 --out /tmp/context.md

# Справка
agy-history --help
```

## 🧠 Как работает глубокое возобновление

Когда ты возобновляешь разговор, скилл:

1. Загружает `transcript_full.jsonl` — **полный, необрезанный** транскрипт
2. Извлекает каждое **сообщение пользователя** и **ответ агента**
3. Отслеживает **прочитанные/изменённые файлы**, **выполненные команды**, **ошибки**
4. Строит подробный документ с контекстом
5. AGY читает всё это и **продолжает натурально** — не нужно ничего объяснять заново

AGY скажет что-то вроде:
> *«Продолжаю с того места, где мы остановились. Мы разрабатывали FastAPI бэкенд, ты попросил добавить JWT аутентификацию. Продолжаю...»*
